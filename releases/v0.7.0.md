# Release v0.7.0 - Real-time Messaging System

**Release Date**: November 2025
**Version**: 0.7.0
**Release Type**: Minor Release

## 🎯 Overview

This release implements a comprehensive real-time messaging system with WebSocket support, allowing users to communicate instantly within the platform. Users can now send messages, see typing indicators, receive read receipts, and get notified of new messages in real-time.

## ✨ New Features

### Real-time Messaging

- **Message Conversations**: View all conversations with other users
- **Real-time Message Delivery**: Messages appear instantly via WebSocket
- **Typing Indicators**: See when the other person is typing
- **Read Receipts**: Know when messages have been read
- **Message from Profile**: Start conversations directly from user profiles
- **Unread Message Badge**: Shows count of unread messages in navbar

### WebSocket Integration

- **Socket Provider**: App-wide WebSocket connection management
- **Auto-reconnection**: Handles connection drops gracefully
- **Event Listeners**: Subscribe to message, read, typing, and delete events
- **Room Management**: Join/leave conversation rooms for typing indicators

## 🔌 API Integration

### Message Endpoints

- `GET /api/messages/conversations` - List all conversations
- `GET /api/messages/conversations/:id` - Get messages in a conversation
- `POST /api/messages` - Send a new message
- `PATCH /api/messages/:id/read` - Mark message as read
- `PATCH /api/messages/conversations/:id/read` - Mark all messages as read
- `GET /api/messages/unread/count` - Get unread message count
- `DELETE /api/messages/:id` - Delete a message

### WebSocket Events

| Event               | Direction | Description                 |
| ------------------- | --------- | --------------------------- |
| `message`           | Server    | New message received        |
| `messageRead`       | Server    | Message marked as read      |
| `conversationRead`  | Server    | Conversation marked as read |
| `messageDeleted`    | Server    | Message deleted             |
| `typing`            | Both      | Typing indicator            |
| `joinConversation`  | Client    | Join conversation room      |
| `leaveConversation` | Client    | Leave conversation room     |

## 🔄 User Flow

### Starting a Conversation

1. Navigate to a user's profile
2. Click "Message User" button
3. If no conversation exists, compose dialog opens
4. Type message and click Send
5. Redirected to conversation page

### Sending Messages

1. Type message in textarea
2. Press Enter or click Send button
3. Message appears immediately for both users
4. Typing indicator shows while typing
5. Read receipt appears when message is read

### Message Notifications

1. New message arrives via WebSocket
2. Unread count badge updates in navbar
3. Conversation moves to top of list
4. Opening conversation marks messages as read
5. Badge count decreases automatically
