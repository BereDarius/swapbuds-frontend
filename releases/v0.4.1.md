# Release v0.4.1 - Items CRUD Complete

**Release Date:** November 24, 2025
**Type:** Feature Release
**Scope:** Frontend - Items Module

---

## 🎯 Overview

Completes the items module by adding full CRUD (Create, Read, Update, Delete) functionality. Users can now create new items, edit their existing items, and delete items they no longer want to list.

---

## ✨ New Features

### 1. **ImageUpload Component**

- **Drag-and-drop interface** for intuitive file uploads
- **Multiple image support** (up to 5 images per item)
- **Cloudinary integration** for reliable image hosting
- **File validation**:
  - Allowed formats: JPG, PNG, WebP
  - Maximum file size: 5MB
- **Image preview grid** with thumbnails
- **Remove images** individually
- **Reorder images** via drag-and-drop
- **Upload progress** indication
- **Primary image indicator** (first image)

### 2. **ItemForm Component**

- **Comprehensive form** with all item fields:
  - Title (3-100 characters, required)
  - Description (10-2000 characters, required)
  - Category (11 options with icons, required)
  - Condition (5 levels, required)
  - Images (1-5 required via ImageUpload)
  - Estimated value (optional numeric field)
  - Delivery methods (multiple checkboxes)
  - Delivery scope (local/national/international)
- **Zod validation** for all fields
- **React Hook Form** integration
- **Dual mode**: Works for both create and edit operations
- **Real-time validation** with error messages
- **Success/error toasts** for user feedback

### 3. **Create Item Page** (`/items/new`)

- Clean, focused UI for item creation
- Uses ItemForm component
- Creates items via API
- Redirects to items list on success

### 4. **Edit Item Page** (`/items/[id]/edit`)

- Loads existing item data
- Pre-fills form with current values
- Updates item via API
- Shows loading state while fetching
- Error handling for missing items

### 5. **Delete Item Functionality**

- Delete button on item detail page
- **Confirmation dialog** prevents accidental deletion
- Success toast and redirect after deletion
- Query cache invalidation for immediate UI update

## 🎨 User Experience

### Create Flow

1. Navigate to items page → Click "Create Item"
2. Fill in required fields (title, description, category, condition)
3. Upload 1-5 images via drag-and-drop or file selector
4. Select delivery methods and scope
5. Optional: Add estimated value
6. Submit → Success toast → Redirect to items list

### Edit Flow

1. View item detail → Click edit icon (owner only)
2. Form pre-filled with current data
3. Modify any fields
4. Submit → Success toast → Redirect to items list

### Delete Flow

1. View item detail → Click delete icon (owner only)
2. Confirmation dialog appears
3. Confirm → Item deleted → Success toast → Redirect to items list

## 📝 Validation Rules

| Field            | Rules                                    |
| ---------------- | ---------------------------------------- |
| Title            | 3-100 characters, required               |
| Description      | 10-2000 characters, required             |
| Category         | Must select one of 11 categories         |
| Condition        | Must select one of 5 conditions          |
| Images           | 1-5 images, JPG/PNG/WebP, max 5MB each   |
| Estimated Value  | 0-1,000,000, optional                    |
| Delivery Methods | At least one method required             |
| Delivery Scope   | Must select local/national/international |
