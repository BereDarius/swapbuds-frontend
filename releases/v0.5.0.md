# Release v0.5.0 - Trade System & User Profiles

**Release Date:** November 24, 2025
**Type:** Major Feature Release

---

## 🎉 Overview

This release adds the complete **Trade System** and **User Profile Management**, bringing SwapBuds to a fully functional trading platform. Users can now propose trades, manage their profiles, and configure privacy settings.

---

## ✨ New Features

### Trade System (Complete)

#### Types & API

- Trade types supporting single-item and multi-item trades
- 6 trade statuses: PENDING, ACCEPTED, REJECTED, CANCELLED, COMPLETED, EXPIRED
- Full trade API client with 8 functions
- TradeFilters for advanced querying

#### Components

- **TradeProposalDialog**: Modal for proposing trades from item detail pages
  - Fetches user's available items
  - Validates delivery method compatibility
  - Optional message field (500 char limit)
  - Empty state with "Create Item" CTA
- **TradeCard**: Displays trade summaries in list views
  - Shows up to 3 items per side with overflow indicator
  - Status badges with 5 color variations
  - Direction indicator (Sent/Received)
  - User info with avatar, username, reputation
  - Links to trade detail page

#### Pages

- **Trades Listing** (`/trades`)
  - Filter tabs for direction (all/sent/received)
  - Filter tabs for status (all 6 statuses)
  - Pagination support (12 per page)
  - Empty states for each filter combination
- **Trade Detail** (`/trades/[id]`)
  - Full trade information with both participants
  - All offered and requested items with thumbnails
  - Delivery method badge
  - Optional message display
  - Timeline showing trade history
  - Action buttons (Accept/Reject/Cancel/Complete)
- **Item Detail Integration**
  - "Propose Trade" button for non-owners
  - Only shown when item status is AVAILABLE
  - Opens TradeProposalDialog

### User Profiles & Settings

#### Types & API

- User profile, statistics, and settings types
- Complete user API client with 9 functions
- GDPR-compliant data export and account deletion

#### Profile Management

- **User Profile Page** (`/profile/[username]`)
  - Public profile view with avatar, bio, location
  - Reputation score with verification badge
  - Member since date
  - Stats cards (reputation, items listed, trades completed)
  - Detailed trade statistics (success rate, response time)
  - Items tab showing user's active listings
  - Edit button for own profile
- **Profile Edit** (`/settings/profile`)
  - Edit username, bio, location
  - Avatar upload with validation (max 5MB)
  - Real-time character counter for bio (500 chars)
  - Cloudinary integration for image uploads

#### Settings Hub

- **Settings Overview** (`/settings`)
  - Card-based navigation to 4 sections
  - Profile, Privacy, Notifications, Account
  - Icon-based visual hierarchy

#### Privacy & Security

- **Privacy Settings** (`/settings/privacy`)
  - Profile visibility (Public/Friends Only/Private)
  - Show email/location toggles
  - Email & push notification preferences
  - Trade & message notifications
  - Marketing emails opt-in
  - Switch components for all toggles

#### Account Management

- **Account Settings** (`/settings/account`)
  - Data export request (GDPR Article 15)
  - Account deletion with password confirmation
  - Danger zone with detailed warnings
  - Lists all data that will be deleted
