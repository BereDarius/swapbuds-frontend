# Release v0.13.0 - Enhanced UI Components & Testing

**Release Date**: November 29, 2025
**Version**: 0.13.0
**Release Type**: Feature Release

## 🎯 Overview

This release focuses on expanding the UI component library, improving test coverage to 95%+, and enhancing user interaction features including comments, messaging, moderation, and verification flows. The release also adds comprehensive admin interfaces for content moderation and user verification management.

## ✨ New Features

### UI Component Library

- **Alert Component**: New alert system with variants (default, destructive, success, warning)
- **Tooltip Component**: Accessible tooltips with Radix UI implementation
- **Scroll Area**: Custom scrollable areas with styled scrollbars
- **Component Testing**: Added Storybook stories and Vitest tests for all new components

### Comments System

- **Comment Display**: Full-featured comment components with threading support
- **Comment Form**: Rich comment creation with validation
- **Comment Actions**: Like, reply, edit, delete, and flag functionality
- **Real-time Updates**: Live comment updates via WebSocket integration

### Messaging System

- **Message Thread**: Comprehensive message display with timestamps
- **Message Composer**: Rich message input with emoji support
- **Message Notifications**: Real-time message notifications
- **Message Status**: Read receipts and delivery status indicators

### Moderation System

- **Flag Dialog**: User-friendly content flagging interface
- **Flag Reasons**: Predefined reasons (INAPPROPRIATE, SPAM, HARASSMENT, SCAM, etc.)
- **Moderation Queue**: Admin interface for reviewing flagged content
- **Content Actions**: Approve, reject, or remove flagged items with one click

### Verification System

- **Document Upload**: Enhanced ID verification with front/back support
- **Selfie Verification**: Optional selfie upload for enhanced trust
- **Verification Status**: Real-time status tracking (PENDING, APPROVED, REJECTED)
- **Admin Verification Queue**: Comprehensive admin interface for document review

### Admin Features

- **Verification Management**: `/admin/verification` - Review pending verifications
- **Moderation Dashboard**: `/admin/moderation` - Manage flagged content
- **Bulk Actions**: Approve/reject multiple items simultaneously
- **Detailed Views**: Full context for verification and moderation decisions

## 📝 Business Rules

### Comments System

- ✅ Users can comment on items they can view
- ✅ Comment authors can edit/delete their own comments
- ✅ Admins/moderators can delete any comments
- ✅ Flagged comments visible only to moderators until reviewed

### Moderation System

- ✅ Any authenticated user can flag content
- ✅ Users cannot flag the same content multiple times
- ✅ Flagged content enters moderation queue automatically
- ✅ Only admins/moderators can resolve flags
- ✅ Approved flags restore content visibility
- ✅ Rejected flags may hide content or ban users

### Verification System

- ✅ Document front is mandatory for verification
- ✅ Document back optional (depends on document type)
- ✅ Selfie optional but increases trust score
- ✅ Users can resubmit verification after rejection (max 3 attempts per 30 days)
- ✅ Admins see all document details for review
