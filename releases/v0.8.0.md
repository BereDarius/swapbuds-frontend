# Release v0.8.0 - Dark Mode & Theme System

**Release Date**: November 2025
**Version**: 0.8.0
**Type**: Minor Release

## 🎯 Overview

This release introduces a comprehensive dark mode implementation with support for light, dark, and system theme preferences. Users can now customize their viewing experience with smooth theme transitions and persistent theme selection across sessions.

## ✨ New Features

### Theme System

- **Dark Mode Support**: Full dark mode implementation with carefully crafted color palette
- **Light Mode**: Optimized light theme with excellent contrast and readability
- **System Theme Detection**: Automatically follows user's system preferences
- **Theme Persistence**: Selected theme saved to localStorage
- **Smooth Transitions**: Seamless switching between themes without jarring flashes

### User Interface

- **Theme Toggle Button**: Sun/Moon icon button in navbar with dropdown menu
- **Mobile Theme Selector**: Theme options in mobile menu
- **Animated Icons**: Smooth rotation animations for sun/moon icons
- **Accessibility**: Screen reader support with proper ARIA labels

## 🎨 UI Components

### New Components

- **ThemeProvider** (`src/components/theme/theme-provider.tsx`): Wraps app with next-themes provider for theme management
- **ThemeToggle** (`src/components/theme/theme-toggle.tsx`): Theme switcher dropdown with light/dark/system options

### Updated Components

- **Navbar**: Added theme toggle button in desktop view between support icon and user avatar
- **Navbar Mobile Menu**: Added theme selector with label and toggle
- **Providers**: Integrated ThemeProvider into app-wide provider hierarchy

## 🏗️ Technical Implementation

### Theme Architecture

- **next-themes Integration**: Uses `next-themes` library for robust theme management
- **Class-based Switching**: Applies `.dark` class to root element for CSS targeting
- **CSS Variables**: Leverages existing OKLCH color variables in globals.css
- **No Flash on Load**: Prevents theme flash with `suppressHydrationWarning` on html element
- **Server-Side Support**: Theme applied before hydration for consistent rendering

### Dependencies

- `next-themes@^0.4.6`: Theme management with localStorage persistence

### Color System

The dark mode uses OKLCH color space for perceptually uniform colors:

```css
.dark {
  --background: oklch(0.15 0.015 240);
  --foreground: oklch(0.95 0.01 240);
  --card: oklch(0.2 0.02 240);
  --primary: oklch(0.65 0.2 195);
  /* ... and more */
}
```

## 📝 Developer Notes

### Using Theme in Custom Components

```tsx
import { useTheme } from "next-themes";

function MyComponent() {
  const { theme, setTheme } = useTheme();

  // Theme will be "light", "dark", or "system"
  console.log(theme);

  // Change theme programmatically
  setTheme("dark");
}
```

### Adding Theme-aware Styles

Use CSS variables for automatic theme adaptation:

```tsx
<div className="bg-background text-foreground">
  <p className="text-muted-foreground">This adapts to theme</p>
</div>
```

Or use dark: modifier for custom styles:

```tsx
<div className="bg-white dark:bg-gray-900">Content</div>
```
