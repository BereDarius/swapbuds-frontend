# Release v0.3.0 - Legal Compliance & GDPR

**Release Date:** November 2024
**Version:** 0.3.0
**Type:** Feature Release

## 🎯 Overview

This release implements comprehensive legal compliance features including GDPR-compliant cookie consent, age verification, legal document management, and Google reCAPTCHA v3 integration. All components are production-ready with full TypeScript support and mobile responsiveness.

## ✨ New Features

### Legal Document Management

- **Legal Document Pages**: Four complete legal pages (Terms of Service, Privacy Policy, Cookie Policy, Community Guidelines)
- **Language Support**: Toggle between English and Romanian with real-time content switching
- **Document Versioning**: Display version numbers and effective dates
- **Markdown Rendering**: Full Markdown support with react-markdown for rich legal content

### Cookie Consent System

- **GDPR-Compliant Banner**: Fixed position banner with Accept All/Reject All/Customize options
- **Cookie Preferences Modal**: Granular control over four cookie categories (Essential, Functional, Analytics, Marketing)
- **Persistent Storage**: LocalStorage persistence with backend synchronization for authenticated users
- **Category Management**: Essential cookies locked, optional cookies user-controllable

### Age Verification

- **Date of Birth Input**: Three-dropdown selector (Day/Month/Year) with leap year handling
- **Real-time Age Calculation**: Uses date-fns for accurate age calculation
- **18+ Enforcement**: Form validation prevents registration for users under 18
- **Age Declaration Checkbox**: User self-declaration of age compliance

### Legal Consent

- **Terms of Service Acceptance**: Required checkbox with link to full document
- **Privacy Policy Acceptance**: Required checkbox with link to full document
- **Marketing Consent**: Optional checkbox for promotional communications
- **Visual Indicators**: Clear required field markers and error messages

### reCAPTCHA Integration

- **Invisible reCAPTCHA v3**: No user interaction required, automatic background verification
- **Token Generation**: Secure token generation on form submission
- **Error Handling**: Graceful fallback if verification fails
- **Loading States**: Submit button disabled until reCAPTCHA loads

## 🏗️ Technical Implementation

### Legal Documents API Client

Created comprehensive API client (`src/lib/api/legal.ts`) with 10 functions:
- `getActiveLegalDocument()` - Fetch current version with language support
- `getLegalDocumentByVersion()` - Fetch specific version
- `listLegalDocumentVersions()` - List all versions
- `acceptLegalDocument()` - Record user acceptance with IP/user agent
- `getUserConsents()` - Retrieve user's consent history
- `checkLegalAcceptanceRequired()` - Check if new acceptance needed
- `updateCookieConsent()` - Update cookie preferences
- `getCookieConsent()` - Retrieve current preferences
- `createLegalDocument()` - Admin: Create new document
- `setActiveLegalDocumentVersion()` - Admin: Activate version

### State Management

- **cookieConsentStore** (`src/stores/cookieConsentStore.ts`): Zustand store with persistence
  - LocalStorage persistence for offline support
  - Backend sync for authenticated users
  - Banner and modal visibility state
  - Accept All/Reject All shortcuts

### TypeScript Types

Created comprehensive type definitions (`src/types/legal.ts`):
- `LegalDocumentType` enum (TOS, PRIVACY_POLICY, COOKIE_POLICY, COMMUNITY_GUIDELINES)
- `Language` enum (EN, RO)
- `LegalDocument` interface
- `LegalConsent` interface
- `CookieConsent` interface
- `LegalAcceptanceStatus` interface
- All API DTOs and response types

### Custom Hooks

- **useRecaptcha** (`src/hooks/useRecaptcha.ts`): Hook for easy reCAPTCHA token generation with error handling and loading states

### Dependencies

New packages added:
- `react-google-recaptcha-v3@1.11.0`: reCAPTCHA v3 integration
- `date-fns@4.1.0`: Date manipulation and age calculation
- `react-markdown@10.1.0`: Markdown rendering for legal documents
- `@radix-ui/react-checkbox` (via shadcn): Accessible checkbox component

### Configuration

New environment variables:

- `NEXT_PUBLIC_RECAPTCHA_SITE_KEY`: Google reCAPTCHA v3 site key (required)

## 🔄 Migration Notes

### For Users

No action required. Cookie consent banner will appear on first visit after update.

### For Developers

1. Add reCAPTCHA site key to environment variables
2. Ensure backend legal endpoints are deployed
3. Load legal documents into database (TOS, Privacy Policy, etc.)

```bash
# Pull latest code
git pull origin main

# Install new dependencies
yarn install

# Add environment variable
echo "NEXT_PUBLIC_RECAPTCHA_SITE_KEY=your_site_key_here" >> .env.local

# Build and start
yarn build
yarn start
```

## 🚀 Deployment

### Prerequisites

- Node.js 18+
- Backend API v0.2.0+ with legal endpoints
- Google reCAPTCHA v3 site key
- Legal documents loaded in backend database

### Installation

```bash
# Pull latest code
git pull origin main

# Install dependencies
yarn install

# Set up environment variables
cp .env.example .env.local
# Add NEXT_PUBLIC_RECAPTCHA_SITE_KEY

# Build and start
yarn build
yarn start
```

### Environment Variables

Add to your `.env.local` file:

```env
NEXT_PUBLIC_RECAPTCHA_SITE_KEY=your_recaptcha_v3_site_key_here
```

Get your reCAPTCHA keys from: https://www.google.com/recaptcha/admin

## 🔐 Security
