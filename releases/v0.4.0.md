# Release v0.4.0 - Items Module (Browse & View)

**Release Date:** November 24, 2025
**Type:** Minor Release
**Focus:** Items Browsing, Viewing, and Core Infrastructure

## 🎯 Overview

This release introduces the items module foundation, enabling users to browse and view items available for trade. This is a major milestone toward the MVP, implementing the core marketplace functionality.

## 📝 Technical Implementation

### New Types (`src/types/item.ts`)

**Enums:**

- `ItemCategory` (11 categories: Electronics, Clothing, Books, Sports, Home, Toys, Collectibles, Art, Music, Games, Other)
- `ItemCondition` (5 levels: New, Like New, Good, Fair, Poor)
- `ItemStatus` (Available, In Trade, Traded, Unavailable)
- `DeliveryMethod` (Physical, Mail)
- `DeliveryScope` (Local, National, International)

**Interfaces:**

- `Item` - Main item entity with all fields
- `ItemImage` - Image with Cloudinary data
- `ItemOwner` - Minimal user data for display
- `CreateItemDto` - Item creation payload
- `UpdateItemDto` - Item update payload
- `ItemFilters` - Filtering and pagination options
- `PaginatedItemsResponse` - API response structure
- `CloudinaryUploadResponse` - Upload response

**Display Constants:**

- `CATEGORY_INFO` - Icons, labels, descriptions for 11 categories
- `CONDITION_INFO` - Labels, descriptions, color coding for 5 conditions
- `DELIVERY_METHOD_INFO` - Icons and descriptions
- `DELIVERY_SCOPE_INFO` - Labels and descriptions

### API Client (`src/lib/api/items.ts`)

**11 API Functions:**

- `getItems()` - Fetch paginated items with filters
- `getItemById()` - Get single item details
- `createItem()` - Create new item (prepared for next release)
- `updateItem()` - Update item (prepared for next release)
- `deleteItem()` - Delete item (prepared for next release)
- `uploadImage()` - Upload to Cloudinary (prepared for next release)
- `deleteImage()` - Delete from Cloudinary (prepared for next release)
- `incrementItemView()` - Track item views
- `getUserItems()` - Get items by user
- `searchItems()` - Search with query

### Components

**ItemCard** (`src/components/items/item-card.tsx`)

- Grid variant: Compact card with image, title, badges
- List variant: Horizontal layout with more details
- Props: `item`, `variant` ("grid" | "list")

## 🔄 Data Flow

### Items Listing

1. User opens `/items`
2. TanStack Query fetches items with filters
3. Results displayed in grid/list view
4. User applies filters → Query refetches
5. Results update with loading skeletons

### Item Detail

1. User clicks item card
2. Navigate to `/items/[id]`
3. Fetch item details
4. Increment view count (background)
5. Display gallery and details
6. Show owner info and actions

## 🔄 Migration Notes

No breaking changes. All additions are backwards compatible.

### For Developers

1. Pull latest changes
2. Copy `.env.example` to `.env.local`
3. Set `NEXT_PUBLIC_API_URL` to your backend
4. Set Cloudinary variables (optional for now)
5. Run `yarn dev`

### For Backend

Ensure the following endpoints are implemented:

- `GET /items` - List items with filters
- `GET /items/:id` - Get item details
- `POST /items/:id/view` - Increment view count
- `POST /items` - Create item (for next release)
- `PATCH /items/:id` - Update item (for next release)
- `DELETE /items/:id` - Delete item (for next release)
