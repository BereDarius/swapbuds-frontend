# Frontend v0.12.0 - Database-Driven Legal Pages

**Release Date:** November 29, 2025

## Overview

Major feature release integrating legal pages (Terms of Service, Privacy Policy, Cookie Policy) with database-driven content, replacing static content with dynamic markdown rendering from backend API.

---

## 🎉 New Features

### Database-Driven Legal Pages

- **Terms of Service page**: Fetches active document from database
- **Privacy Policy page**: Fetches active document from database
- **Cookie Policy page**: NEW - Created with database integration
- **Dynamic content**: All pages render markdown from backend API
- **Version display**: Shows document version and effective date
- **Loading states**: Skeleton loaders during content fetch
- **Error handling**: Graceful error messages if content unavailable

### Markdown Rendering Component

- **MarkdownContent component**: Reusable component for rendering legal markdown
- **Styled output**: Custom styling with TailwindCSS prose classes
- **Dark mode support**: Automatic dark mode via `dark:prose-invert`
- **Custom elements**: Styled headings, paragraphs, lists, links, blockquotes, code
- **Accessibility**: Proper semantic HTML and ARIA attributes

## 🐛 Bug Fixes

### Enum Mismatch

- **Issue**: Frontend used `TOS` but backend expects `TERMS_OF_SERVICE`
- **Fix**: Updated enum to match database schema exactly
- **Impact**: 500 errors resolved, API calls now succeed

### Field Name Mismatches

- **Issue**: Frontend expected `effectiveFrom` but backend returns `effectiveAt`
- **Fix**: Updated interface to use correct field name
- **Result**: Dates display correctly ("Effective from 1/1/2025")

### Content Field Structure

- **Issue**: Frontend expected `contentEn`/`contentRo` but backend returns `content`
- **Fix**: Backend returns only requested language as single `content` field
- **Result**: Markdown content renders correctly

## 🧪 Technical Details

### React Query Integration

```tsx
const { data: document, isLoading } = useQuery({
  queryKey: ["legal-document", LegalDocumentType.TERMS_OF_SERVICE],
  queryFn: () =>
    getActiveLegalDocument(LegalDocumentType.TERMS_OF_SERVICE, Language.EN),
});
```

### Markdown Component Usage

```tsx
<MarkdownContent content={document.content} />
```

### API Response Handling

- Success: Render markdown content
- Loading: Show skeleton placeholders
- Error: Show error message in destructive card
- Data validation: Check document exists before rendering
