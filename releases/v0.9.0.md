# Release v0.9.0 - Complete Admin, Support & Safety Features

**Release Date**: November 24, 2025
**Version**: 0.9.0
**Release Type**: Minor Release

## 🎯 Overview

This major feature release completes all critical launch requirements, bringing the platform to 95% completion. The release adds comprehensive admin tools, moderation systems, support infrastructure, ID verification, and dispute resolution - essential features for platform safety, governance, and user trust.

## ✨ New Features

### 🛡️ Admin Dashboard

- **Admin Layout**: Protected routes with role-based access (ADMIN/MODERATOR only)
- **Platform Dashboard**: Key metrics, statistics, and system health monitoring
- **User Management**: Search, view, ban/unban, role changes, account controls
- **Audit Logs**: Complete history of admin actions with filtering and search
- **Item Management**: Placeholder for flagged items review (stub)
- **Trade Management**: Placeholder for problematic trades review (stub)

### 🚨 Moderation Tools

- **Flag Dialog Component**: Reusable reporting system for content/users
- **Moderation Dashboard**: Review flagged content with filters and actions
- **Flag Reasons**: SPAM, INAPPROPRIATE, SCAM, HARASSMENT, COPYRIGHT, FAKE, OTHER
- **Moderation Actions**: Approve, reject, remove content with notes
- **Item Flagging**: Report button integrated into item detail pages
- **Multi-entity Support**: Flag items, comments, users, and trades

### 🎫 Support Ticket System

- **Ticket List**: View all support tickets with status and priority
- **Create Ticket**: Submit support requests with priority selection
- **Live Chat**: Real-time support conversations via WebSocket
- **Typing Indicators**: See when support is typing
- **Status Tracking**: OPEN, IN_PROGRESS, RESOLVED, CLOSED states
- **Priority Levels**: LOW, MEDIUM, HIGH, URGENT
- **Auto-scroll**: Smooth chat experience with auto-scroll to latest messages

### ⚖️ Dispute System

- **Dispute List**: View all disputes with status badges
- **Create Dispute**: Report problems with trades
- **Dispute Reasons**: ITEM_NOT_RECEIVED, NOT_AS_DESCRIBED, DAMAGED, COUNTERFEIT, etc.
- **Evidence Upload**: Attach photos and descriptions
- **Resolution Tracking**: PENDING, INVESTIGATING, RESOLVED, REJECTED states
- **Trade Integration**: "Report Problem" button in trade detail pages

### ✅ ID Verification

- **Verification Page**: Document upload and status display
- **Document Types**: ID_CARD, PASSPORT, DRIVERS_LICENSE
- **Cloudinary Integration**: Secure document upload with face detection
- **Status Tracking**: PENDING, APPROVED, REJECTED with review times
- **Benefits Display**: Shows advantages of verified status
- **Resubmission**: Upload new documents if rejected

### 👤 User Type System

- **Centralized Types**: Consolidated User interface in `types/auth.ts`
- **Role Field**: Support for USER, MODERATOR, SUPPORT, ADMIN roles
- **Auth Store Fix**: Proper type imports for role-based access control
- **Type Safety**: Fixed TypeScript errors across admin/moderation features

## 🔌 API Integration

### Admin Endpoints

- `GET /api/admin/stats` - Platform statistics
- `GET /api/admin/users` - User management
- `PATCH /api/admin/users/:id/ban` - Ban/unban users
- `PATCH /api/admin/users/:id/role` - Change user roles
- `GET /api/admin/audit-logs` - Admin action history

### Moderation Endpoints

- `GET /api/moderation/flags` - List flagged content
- `POST /api/moderation/flags` - Create content flag
- `PATCH /api/moderation/flags/:id` - Resolve flag
- `GET /api/moderation/flags/:id` - Get flag details

### Support Endpoints

- `GET /api/support/tickets` - List support tickets
- `POST /api/support/tickets` - Create ticket
- `GET /api/support/tickets/:id` - Get ticket details
- `POST /api/support/tickets/:id/messages` - Send message

### Dispute Endpoints

- `GET /api/disputes` - List disputes
- `POST /api/disputes` - Create dispute
- `GET /api/disputes/:id` - Get dispute details
- `PATCH /api/disputes/:id/resolve` - Resolve dispute

### Verification Endpoints

- `POST /api/verification/upload` - Upload verification document
- `GET /api/verification/status` - Check verification status
- `GET /api/verification` - Get verification details

### WebSocket Events (Support)

| Event                       | Direction | Description          |
| --------------------------- | --------- | -------------------- |
| `supportMessage`            | Server    | New support message  |
| `supportTyping`             | Both      | Typing indicator     |
| `supportTicketStatusChange` | Server    | Ticket status update |
| `joinSupportTicket`         | Client    | Join ticket room     |
| `leaveSupportTicket`        | Client    | Leave ticket room    |
